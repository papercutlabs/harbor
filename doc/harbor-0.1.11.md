# Harbor 0.1.11

Popups now have a distinct panel background, a blue outline, and a brighter title. The conversation behind an open popup is dimmed so menus no longer blend into message panels. Closing the popup restores the conversation colors and reading position.

Validated the narrow message-action menu, outside-click dismissal, attachment caption editing, chat picker, and update/restart flow in native terminal tests.

Apply the update from Harbor’s update prompt; existing sessions keep running until you choose to restart.
