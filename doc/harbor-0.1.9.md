# Harbor 0.1.9

A stationary left-click no longer selects or highlights a message. Left-drag selects only text and copies it on release. Left-clicking a message also clears any previous whole-message highlight from keyboard browsing or a right-click menu.

Right-click still opens Reply, Forward, Copy text. Keyboard message browsing remains available with Esc and the arrow keys.

Native mouse tests verify that closing a right-click menu and left-clicking another message restores ordinary panel colors rather than moving the whole-message highlight. Drag-copy, right-click actions, reply/forward/copy, and drafts are also checked.
