# Harbor 0.1.18

1. Telegram messages keep their native formatting, including quotes, underlines, spoilers and code blocks. Copy code preserves the original spacing and punctuation.
2. Message actions can visit the message being replied to and return to the previous reading position without changing the draft.
3. Commands includes conversation search and pinned messages. Message actions offer the available reactions and a chooser when a message has several links.

These actions use the existing menus. Office's Desk entries continue to return to the same Harbor conversation and draft.
